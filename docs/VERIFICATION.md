## 浏览器交互与布局

在最终应用上检查了桌面三栏布局和390px手机宽度：手机视图未见横向溢出，底部评论/商品/分享/点赞入口可见。浏览器实际完成：

1. 商品列表 → 填写演示联系人/手机号/数量 → 提交 → 返回数据库订单号和明确“未付款”结果。
2. 发送评论 → 在观看端评论区域显示。
3. 点击签到 → 返回10演示积分及当前会话限制说明。
4. 使用重启前的订单号和手机号查询，返回“演示待处理（未付款）”。
5. 缺少媒体时显示“待接入播放源”，没有生成虚假播放画面或观看量。
