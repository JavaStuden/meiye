# 美业直播小程序

这是微信原生小程序工程，可直接用微信开发者工具导入本目录。直播列表与观看页现通过 HTTPS 读取 meiye 后端的场次、回放状态、评论和商品数据；商品、订单、营销及个人中心等其他页面仍使用本地演示数据。

## 预览

1. 安装并打开微信开发者工具。
2. 选择“导入项目”，目录选本 `miniprogram` 文件夹。
3. `project.config.json` 已填写本工程关联的 AppID；如果在其他小程序主体账号下导入，请换成该账号有权限的 AppID。
4. 确认公众平台已配置 `voice.yourunshi.online` 的 request 和 download 合法域名，再编译预览。

## 当前演示边界

- 除直播列表与观看页只读数据外，其他页面数据仍在 `utils/demo-data.js` 并存入本机缓存；购物车、优惠券、订单状态、积分和活动交互属于演示数据。
- 直播观看页使用后台配置的媒体地址；当前线上房间尚未配置可播放源，因此显示后台封面和未配置提示。商品、订单和营销操作仍有本地演示数据，不扣款、不发货、不结算。
- 微信分享入口使用原生分享菜单；没有微信登录、支付、真实客服、连麦、推送消息或实时直播服务。
- 后端只读地址在 `utils/backend.js` 中固定为 `https://voice.yourunshi.online/meiye`。请在微信公众平台的“开发管理 → 开发设置 → 服务器域名”将 `voice.yourunshi.online` 加入 request/download 合法域名，再上传小程序代码。
- 评论列表与发送已接入后台数据库；昵称由观众填写，发送频率受后台限制。点赞、预约、下单、登录和支付仍未接入。
- 正式发布还需小程序主体/服务类目、备案、隐私声明、服务器域名配置和平台审核。

## 页面结构

- `pages/home`：直播/预告/录播列表。
- `pages/store`、`pages/category`、`pages/cart`：商城首页、商品分类和购物车。
- `pages/watch`：观看页、入场通知、评论、点赞、分享和关联商品。
- `pages/watch-share`：分享卡片和小程序码使用的沉浸式观看入口；小程序内部跳转仍使用带原生返回导航的 `pages/watch`。
- `pages/feature`：商品详情、结算/订单和截图中展示的营销/个人服务子页面。
- `pages/mine`：余额/积分/优惠券概览、订单和个人服务入口。
- `utils/demo-data.js`：共享的本地演示数据与持久化。

## 接真实 API 前的注意事项

项目后端当前面向网页会话：写接口需要 CSRF token 和 session cookie。小程序不能直接复用网页登录态；接入时需要专门设计小程序登录/鉴权 API，再设置 HTTPS 合法域名。不要简单把网页的写请求直接暴露给小程序。

这不是可直接提交审核的生产版本；发布前应按小程序主体资料、实际服务类目和微信后台要求完成配置，并移除不适用于真实服务的模拟承诺。
