# 美业直播小程序观看端（演示版）

这是从 `https://voice.yourunshi.online/meiye/meiye/?view=mini&room=1` 的小程序观看端页面结构迁移出来的微信原生小程序演示工程。当前覆盖直播列表/直播间、商城首页、商品分类/详情、购物车、我的、录播回放、订单、优惠券、秒杀、拼团、砍价、签到积分、充值、抽奖、推广/邀请榜、提现、门店、消息和资讯等用户端页面。它不依赖 Node 构建，可直接用微信开发者工具导入本目录。

## 预览

1. 安装并打开微信开发者工具。
2. 选择“导入项目”，目录选本 `miniprogram` 文件夹。
3. `project.config.json` 已填写本工程关联的 AppID；如果在其他小程序主体账号下导入，请换成该账号有权限的 AppID。
4. 编译后可从底部“直播、商品、分类、购物车、我的”五个入口进入页面；直播间、商品详情、订单及营销页面由页面按钮继续进入。

## 当前演示边界

- 页面数据在 `utils/demo-data.js`，并存入小程序本机缓存；评论、收藏、购物车、优惠券、订单状态、积分和活动交互互相联动，属于演示数据。
- 直播与预告播放区使用项目图片素材；“肩颈护理实操 · 精品回放”使用网页演示视频 `https://voice.yourunshi.online/meiye/meiye/assets/reference.mp4`。订单和营销操作只改变本机演示状态，不扣款、不发货、不结算。
- 微信分享入口使用原生分享菜单；没有微信登录、支付、真实客服、连麦、推送消息或实时直播服务。
- 顶层 `app.js` 中 `demoMode` 默认为 `true`。后续接入后端时再配置正式 API、微信合法域名及接口鉴权。
- 正式发布还需小程序主体/服务类目、备案、隐私声明、服务器域名配置和平台审核。

## 页面结构

- `pages/home`：直播/预告/录播列表。
- `pages/store`、`pages/category`、`pages/cart`：商城首页、商品分类和购物车。
- `pages/watch`：观看页、入场通知、评论、点赞、分享和关联商品。
- `pages/feature`：商品详情、结算/订单和截图中展示的营销/个人服务子页面。
- `pages/mine`：余额/积分/优惠券概览、订单和个人服务入口。
- `utils/demo-data.js`：共享的本地演示数据与持久化。

## 接真实 API 前的注意事项

项目后端当前面向网页会话：写接口需要 CSRF token 和 session cookie。小程序不能直接复用网页登录态；接入时需要专门设计小程序登录/鉴权 API，再设置 HTTPS 合法域名。不要简单把网页的写请求直接暴露给小程序。

这不是可直接提交审核的生产版本；发布前应按小程序主体资料、实际服务类目和微信后台要求完成配置，并移除不适用于真实服务的模拟承诺。
