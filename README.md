# 美业直播 · Java 应用

Java 21、Spring Boot 3.5.16、Thymeleaf、原生 CSS/JavaScript、Spring Security、Spring Data JPA、H2。无需 Node、前端构建工具或外部 CDN。界面根据四个公开参考入口独立实现，详细证据见 [公开页面审查](docs/REFERENCE-AUDIT.md)。

## 已交付的功能

- 实时直播、录播回放、定时伪直播三类观看页，保留原 `view=mini&room=N` 入口；另有 H5 入口、适配手机的布局。
- 后台登录、场次列表及搜索筛选、新建/修改场次、状态切换、公告、评论开关、封面与媒体源配置。
- 商品配置：添加、编辑、关联场次与设置售价；观看端商品列表、演示下单、订单号加手机号查询、后台订单列表。
- 评论存入数据库并每 4 秒同步，点赞原子累加；同一浏览器会话每日一次签到（演示积分）。已打开页面会同步评论开关、公告与场次信息，切换模式时自动刷新。
- MP4 原生播放；HLS 使用随包附带的 hls.js。录播可暂停、拖动、倍速；伪直播按服务器时间计算统一进度。
- 管理员可通过服务端媒体 API 上传视频到私有腾讯云 COS；素材元数据写入 H2，浏览器只接收限时签名链接。
- 所有媒体源默认留空；封面是原创 SVG 插画。缺少媒体、未开始、已结束、媒体不可播放分别显示明确状态。
- 业务数据存入 H2 文件数据库，刷新和重启后保留；不存在虚构在线人数、成交额或自动生成的观众留言。

## 启动

需要 JDK 21 或以上。完整交付包内含 `target/meiye-live-1.0.0.jar`，运行它无需 Maven或联网。Windows 的启动脚本兼容 PowerShell，Linux/macOS 可使用 shell 脚本。

```powershell
# 在解压后的 meiye-live 文件夹运行
$env:JAVA_HOME = '你的 JDK 21 安装目录'
$env:MEIYE_ADMIN_PASSWORD = Read-Host '设置本次启动使用的后台密码'
.\start.ps1
```

```sh
export MEIYE_ADMIN_PASSWORD='在本机设置自己的后台密码'
sh start.sh
```

如果PowerShell的执行策略阻止脚本运行，也可直接运行：

```sh
java -jar target/meiye-live-1.0.0.jar
```

默认后台账号是 `admin`。如果没有设置 `MEIYE_ADMIN_PASSWORD`，启动日志会显示随机临时密码，每次启动更换。密码不写入源码；后台登录态最长空闲 60 分钟。默认只监听本机 `127.0.0.1:8080`。

| 页面 | 本机地址 |
| --- | --- |
| 后台 | http://127.0.0.1:8080/admin |
| 实时直播 1 | http://127.0.0.1:8080/meiye/?view=mini&room=1 |
| 录播 3 | http://127.0.0.1:8080/meiye/?view=mini&room=3 |
| 伪直播 2 | http://127.0.0.1:8080/meiye/?view=mini&room=2 |
| H5 | http://127.0.0.1:8080/meiye/?view=h5&room=1 |

启动脚本会在项目目录创建 `data/`。停止服务后，可备份这个目录中的数据库文件。`data/` 不随源码或交付压缩包分发。避免同时运行两个指向同一 H2 文件的进程。

## 从源码构建和测试

需要 Maven 3.9+ 与 JDK 21+；首次构建需要访问 Maven Central。

```sh
mvn clean verify
java -jar target/meiye-live-1.0.0.jar
```

仅有源码时，启动脚本会先尝试调用 Maven 打包。强制重新构建：`.\start.ps1 -Build` 或 `sh start.sh --build`。测试使用独立的内存数据库，不修改运行数据。

## 接入媒体

1. 登录后台，在目标场次点击配置。
2. 填入自己有权使用且浏览器可访问的 HTTPS MP4 或 HLS `.m3u8` 地址。
3. 实时直播设为 `直播中`；录播设为 `已结束` 仍可回放；伪直播设置北京时间开始时间、媒体实际时长与 `待开播` 状态。
4. 保存后打开观看页。播放状态每 8 秒更新，用户点击“开始播放”才播放媒体。

也支持 `/media/...` 形式的同源路径：把媒体放在 `src/main/resources/static/media/` 后重新构建。该目录不提供在线上传服务。不应把媒体服务的私有推流密钥写入浏览器播放地址。

HLS 使用本地附带的播放器，无需 CDN。媒体服务仍须提供正确的 CORS、Content-Type、TLS 与编解码格式；HTTPS 页面应使用 HTTPS 媒体。播放器根据 `.m3u8` 扩展名识别 HLS，其他地址按浏览器支持的媒体格式处理。资源不可用会显示失败提示，不能保证任意第三方地址可播。

伪直播是按同一个服务器排期对录播进行浏览器定位，加入时间不同也会计算同一进度；它不是服务器重新推流。每 8 秒校准，偏移超过约 3 秒时调整，不能保证帧级同步。源文件可被有权限的浏览器下载，付费防盗播/DRM 不在本实现内。原参考站的伪直播采用每人独立播放进度，本应用在这一点上作了明确改进。

## 配置项

直播间分享码的服务器配置、小程序发布要求与验收方法见 [微信分享码接入](docs/WECHAT-SHARE.md)。

| 环境变量 | 默认值 / 用途 |
| --- | --- |
| `PORT` | `8080` |
| `SERVER_ADDRESS` | `127.0.0.1`；远程部署时按自己的网络配置修改 |
| `MEIYE_ADMIN_USERNAME` | `admin` |
| `MEIYE_ADMIN_PASSWORD` | 未设置时生成随机临时密码 |
| `DB_URL` | `jdbc:h2:file:./data/meiye;DB_CLOSE_ON_EXIT=FALSE` |
| `DB_USERNAME` / `DB_PASSWORD` | H2 用户名 `sa` / 空密码 |
| `MEIYE_LIVE_URL` | 首次空库初始化房间 1 的媒体源 |
| `MEIYE_REPLAY_URL` | 首次空库初始化房间 3 的媒体源 |
| `MEIYE_PSEUDO_URL` | 首次空库初始化房间 2 的媒体源 |
| `COS_BUCKET` / `COS_REGION` | 私有媒体桶，默认 `meiye-live-media-1344161993` / `ap-guangzhou` |
| `COS_SECRET_ID` / `COS_SECRET_KEY` | COS 专用 CAM 用户凭证，只能配置在服务器环境变量中 |

媒体上传入口为需管理员登录的 `/api/admin/media`，单文件上限 2 GB。CAM 策略应限定到该桶的对象读取、写入和分片上传权限。浏览器端签名链接有效期为 6 小时。

媒体环境变量只在空库播种时读取；已有场次须通过后台修改。伪直播初始排期是首次启动后一小时，媒体仍为空。端口也可通过 `java -jar ... --server.port=9090` 修改。需要其他数据库时另行添加 JDBC 驱动和迁移脚本；当前交付只验证 H2。正式部署应使用 HTTPS、持久卷备份、受控后台入口和明确的密码；当前账户模型为单管理员、单应用实例。

## 交付边界

这是可运行的核心 Java 项目，覆盖观看、场次/商品管理、互动和演示订单。原参考站是浏览器本地业务原型，其全部菜单不等于真实已接入业务。

| 原页面可见能力 | 此项目实际行为 |
| --- | --- |
| 抖音/视频号 RTMP 推流、手机扫码录制、自动录制/归档/转码 | RTMP 会话与 Qwen 音视频混流尚未实现；页面不再显示伪造线路 |
| 微信小程序 | 已提供 `miniprogram/` 原生观看端演示工程；使用本地演示数据，尚未接入微信登录、真实直播组件、支付或发布 |
| 微信支付、退款、提现、余额 | 未接入；所有订单为 `DEMO_PENDING`，没有扣款/退款/发货 |
| 商品库存、物流、面单/小票、门店核销 | 未接入；商品为演示目录，没有库存或履约系统 |
| 优惠券、秒杀、拼团、砍价、抽奖、分销 | 显示“待接入”说明；没有模拟真实中奖、佣金或优惠结算 |
| 签到积分 | 当前匿名会话每天一次 10 演示积分，不是持久会员积分账本 |
| 评论、点赞 | 真实存库；匿名昵称，不是实名/微信身份；基础会话限频，无审核/禁言系统 |
| 自动评论/直播助手 | PC 演示原型支持按场次配置、启停、删除机器人评论任务，并把话术写入本机评论流；任务状态保存在浏览器，不接第三方直播平台，也不代表真实观众或服务端任务 |
| 礼物、连麦、原生微信分享 | 未接入；分享入口提供复制观看网址 |
| 会员、客服、消息、商城装修、财务、报表、权限角色 | 不在核心实现；后台仅开放已实现页面 |
| 并发、低延迟、CDN、监控、风控承诺 | 未压测、未验证生产指标；目前是单进程演示应用 |

原始 PPT、生产 API、真实直播源、媒体采集 APP、支付/微信/物流/短信/打印服务凭据均未提供；这些能力无法仅凭公开原型还原。媒体接入和生产业务扩展需要对应服务，不应把本地业务流程标记为真实直播或真实支付。

当前录播管理演示还支持在创建场次时从素材列表选择视频、或选取本机视频并在当前浏览器临时预览，以及记忆播放、循环播放和评论时间轴循环设置。直播模式可配置封面、背景、回放、连麦入口、累计观看人数、聊天和首页入口。场次、机器人任务及本机文件预览属于浏览器演示状态；本机选取的文件刷新后需重新选择。腾讯云 COS 尚未创建存储桶或接入上传，封面/背景图片同样不会持久化。真实推流、连麦、云媒体存储和多用户共享仍需服务端与对应云服务。
